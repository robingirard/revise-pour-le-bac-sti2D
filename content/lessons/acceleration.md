# Accélération et équations du mouvement

## Accéléré, freiné, uniforme

- la vitesse **augmente** : mouvement **accéléré** ;
- la vitesse **diminue** : mouvement **freiné** (décéléré) ;
- la vitesse **ne change pas** : mouvement **uniforme**.

L'**accélération** est la variation de la vitesse par unité de temps (en m/s²) : c'est la **dérivée** de la vitesse.
Accélération **nulle** → mouvement uniforme ; accélération **constante non nulle** → mouvement **uniformément varié**.

## Sur une trajectoire circulaire

{{fig:cinematique-acceleration}}

Le vecteur accélération a deux composantes : **a t** (tangentielle, = dV/dt) et **a n** (normale, dirigée vers le centre) :

**a n = V² ÷ r**. Si la vitesse est constante, a t = 0 mais a n n'est **pas nulle** : la direction de la vitesse change.

## Les équations du mouvement

| | Translation rectiligne | Rotation autour d'un axe fixe |
|---|---|---|
| **Uniforme** | a = 0 ; v = v0 ; x(t) = v0 × t + x0 | θ'' = 0 ; θ' = θ'0 ; θ(t) = θ'0 × t + θ0 |
| **Uniformément varié** | a = a0 ; v(t) = a0 × t + v0 ; x(t) = ½ a0 t² + v0 t + x0 | θ'' = θ''0 ; θ'(t) = θ''0 t + θ'0 ; θ(t) = ½ θ''0 t² + θ'0 t + θ0 |
