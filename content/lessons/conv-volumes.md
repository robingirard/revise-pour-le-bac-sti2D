# Volumes et capacités

## Le facteur mille

Un volume est le produit de **trois** longueurs. Le facteur $10$ des longueurs y intervient donc trois fois, et l'on passe d'une unité de volume à la suivante en multipliant par $1\,000$.

{{fig:conv-cube-metre}}

| Unité | en $\mathrm{m^3}$ | | Unité | en $\mathrm{m^3}$ |
|---|---|---|---|---|
| $\mathrm{km^3}$ | $10^{9}$ | | $\mathrm{dm^3}$ | $10^{-3}$ |
| $\mathrm{hm^3}$ | $10^{6}$ | | $\mathrm{cm^3}$ | $10^{-6}$ |
| $\mathrm{dam^3}$ | $10^{3}$ | | $\mathrm{mm^3}$ | $10^{-9}$ |

Les exposants vont **de trois en trois**, et le tableau des volumes réserve **trois** cases par unité — une pour chaque puissance de dix franchie.

Trois familles, trois facteurs, une seule raison :

| Grandeur | Nombre de longueurs | Facteur entre deux unités voisines |
|---|---|---|
| Longueur | 1 | $10$ |
| Surface | 2 | $100$ |
| Volume | 3 | $1\,000$ |

## Le pont vers les capacités

Les volumes se mesurent aussi en litres. Un seul lien à retenir, tout le reste en découle :

$$\boxed{1\ \ell = 1\ \mathrm{dm^3}}$$

D'où, sans rien apprendre de plus :

- $1\ \mathrm{m^3}=1\,000\ \mathrm{dm^3}=1\,000\ \ell$ ;
- $1\ \mathrm{cm^3}=1$ mL (les graduations d'une seringue se lisent dans les deux unités) ;
- $1$ hL $=100\ \ell=0{,}1\ \mathrm{m^3}$.

**La méthode qui évite les erreurs** : rester dans le tableau des volumes tant qu'on peut, et n'utiliser le pont vers les litres **qu'une seule fois**, au bon endroit.

$$0{,}0025\ \mathrm{hm^3}\ \xrightarrow{\ \times10^{6}\ }\ 2\,500\ \mathrm{m^3}$$
$$2\,500\ \mathrm{m^3}\ \xrightarrow{\ \times1\,000\ }\ 2\,500\,000\ \ell$$

## Calculer un volume, puis le convertir

{{fig:conv-cercle-cylindre}}

Le volume d'un cylindre est l'aire de son disque de base multipliée par sa hauteur : le rayon est **au carré**, la hauteur non.

$$V=\pi R^{2}h=\pi\times3^{2}\times12=339{,}3\ \mathrm{cm^3}=0{,}339\ \ell$$

Un tiers de litre : l'ordre de grandeur d'une canette, ce qui confirme le calcul.

Pour un parallélépipède, $V=L\times l\times h$ — à condition que les trois dimensions soient dans la même unité. Une citerne de $2\ \mathrm{m}\times1{,}5\ \mathrm{m}\times1{,}2\ \mathrm{m}$ contient $3{,}6\ \mathrm{m^3}$, soit $3\,600$ litres.

## Vérifier par l'ordre de grandeur

Quelques repères qui permettent de repérer une erreur de conversion sans refaire le calcul :

- une bouteille d'eau : $1{,}5\ \ell$, soit $1{,}5\ \mathrm{dm^3}$ ;
- une baignoire : environ $150\ \ell$ ;
- une piscine familiale : quelques dizaines de $\mathrm{m^3}$, soit des dizaines de milliers de litres ;
- une retenue de barrage : des dizaines de millions de $\mathrm{m^3}$, soit des $\mathrm{hm^3}$.

« Une piscine de $50\ \mathrm{m^3}$ contient $50\,000\ \mathrm{cm^3}$ » se repère ainsi : $50\,000\ \mathrm{cm^3}$, ce sont $50$ litres — une glacière. Le nombre était juste, c'est l'unité qui ne l'était pas : $50\ \mathrm{m^3}=50\,000\ \ell$.
