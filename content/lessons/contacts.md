# Des surfaces de contact à la liaison

Pour reconnaître une liaison dans un mécanisme réel, on regarde **la forme des surfaces en contact** :

| Contact | Liaison |
|---|---|
| Pièces vissées, soudées, collées, emmanchées | **Encastrement** |
| Cylindre dans cylindre **long** + arrêt en translation (épaulement, circlips) | **Pivot** |
| Cylindre dans cylindre long, **sans** arrêt | **Pivot glissant** |
| Filetage dans taraudage (vis dans écrou) | **Hélicoïdale** |
| Deux contacts plan sur plan (section rectangulaire ou prismatique) | **Glissière** |
| Sphère dans sphère creuse | **Rotule** |
| Plan sur plan | **Appui plan** |
| Cylindre sur plan (contact suivant une ligne) | **Linéaire rectiligne** |
| Sphère dans cylindre (contact suivant un cercle) | **Linéaire annulaire** |
| Sphère sur plan (contact en un point) | **Ponctuelle** |

Deux questions à se poser devant un contact :

1. **Quelle forme** ont les surfaces (plan, cylindre, sphère, filetage) ?
2. Y a-t-il un **arrêt** (épaulement, goupille, butée) qui bloque une translation ?
