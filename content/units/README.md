# Unités supplémentaires

Chaque fichier `NN-<slug>.yaml` de ce dossier contient `units: [ … ]` au même format que `../units.yaml`
(unités → compétences → `lesson`, `prerequisites`, `generators`, `items`). Les fichiers sont chargés dans
l'ordre alphabétique après `units.yaml` ; les identifiants de compétences doivent être uniques dans tout le projet.
